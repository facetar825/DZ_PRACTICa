Основной файл для сдачи: [Практика_Функции_Мингазов_Ахнаф.sql](Практика_Функции_Мингазов_Ахнаф.sql).

## Выполнение заданий

1. `college.GetStudentStatus`: скалярная функция статуса. От 4,5 до 5 — «Отличник», от 3,5 до значения менее 4,5 — «Хорошист», ниже 3,5 — «Требуется дополнительная подготовка». Для NULL и значений вне 0–5 предусмотрены отдельные ответы.
2. `college.CalculateDiscount`: итоговая цена `цена × (1 − скидка / 100)`, округлённая до копеек. 10000 и 10% → 9000; 25000 и 15% → 21250. Некорректные аргументы возвращают NULL.
3. Аналитический SELECT соединяет студентов и группы, получает статус через функцию. Дополнительно показана функция в WHERE.
4. `college.GetStudentsByGroup`: inline TVF возвращает id, имя, возраст, балл и group_id. Проверены группы 1, 2, 3 и отсутствующая группа.
5. TVF используется в FROM и соединяется с groups через JOIN.
6. `college.GetAgeCategory`: до 18 — «Несовершеннолетний», 18–20 включительно — «Студент», старше 20 — «Взрослый».

Итоговый запрос выводит имя, группу, возраст, средний балл, статус успеваемости и возрастную категорию. Обе категории вычисляются функциями.

## Ответы на вопросы для самопроверки

1. **Пользовательская функция** — объект базы данных с именем, параметрами и определённым типом результата, содержащий повторно используемую логику.
2. **Scalar и TVF:** первая возвращает одно значение, вторая — набор строк и столбцов.
3. **Результат scalar-функции:** одно значение объявленного типа, например nvarchar или decimal.
4. **Результат inline TVF:** таблица, определяемая одним SELECT после RETURN.
5. **Где использовать:** scalar-функцию — в выражениях SELECT, WHERE, ORDER BY; TVF — в FROM, JOIN, APPLY.
6. **Отличие от процедуры:** функцию можно включать в запрос как выражение или табличный источник. Процедуру вызывают через EXEC; она может изменять данные и возвращать несколько наборов результатов. T-SQL UDF имеет ограничения на побочные действия и не предназначена для изменения состояния базы.
7. **Отличие от VIEW:** представление задаёт именованный запрос без входных параметров; функция принимает параметры и может возвращать как скаляр, так и таблицу.
8. **Зачем параметры:** чтобы повторно применять одну логику к разным баллам, возрастам, ценам или группам.
9. **Зачем объявленный тип:** SQL Server должен знать контракт результата, допустимые операции и преобразования; для scalar тип указан в RETURNS, для inline TVF столбцы определяет SELECT.
10. **Когда упрощает SQL:** при повторении правил статуса, возрастной категории, скидки или отбора студентов по группе. При этом следует учитывать стоимость вызовов функции в большом запросе.
