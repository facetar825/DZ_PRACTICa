# Проверка выполнения

Дата: 5 октября 2026 года. Среда: локальный Microsoft SQL Server 2025, sqlcmd, Windows Authentication. База проверки: `CollegeDB_HW_20261005`.

Все девять файлов `00`..`08` выполнены через `sqlcmd -b -f 65001` с кодом завершения 0. Итог файла `08_Проверки.sql`: «Все проверки пройдены».

Весь набор также повторно выполнен с кодом 0 для каждого файла: проверена возможность повторного запуска без пересоздания базы и накопления демонстрационных изменений.

## Подтверждённые результаты

- В базе 3 группы, 12 студентов и 30 оценок. VIEW возвращает всех 12 студентов.
- У студента 1 три оценки, среднее 4.666666; дробная часть не потеряна. После тестового добавления пятёрки - четыре оценки и среднее 4.750000.
- У студента 12 нет оценок: количество 0, среднее/минимум/максимум NULL.
- Процедура возвращает статистику существующего студента, а для отсутствующего выдаёт ошибку 50001. OUTPUT возвращает 5 студентов группы 1; RETURN равен 0.
- Проверены NULL, 3.99, 4.00, 4.49, 4.50, 4.79, 4.80, 5.00 и 5.01 для стипендии. По порогу 4.5 Inline TVF возвращает 7 студентов, по NULL - ни одного.
- Один UPDATE группы 1 создаёт пять строк аудита. Изменение имени без изменения балла не создаёт лишних записей. Переходы NULL → 4.00 → NULL записываются.
- INSERT двух студентов создаёт две строки аудита. Недопустимые UPDATE и INSERT с баллом 5.5 отклоняются ошибкой 50002.
- Рекурсивный CTE формирует 20 чисел от 1 до 20; сумма равна 210.
- Топ-3 содержит 9 студентов, по три в каждой группе. Среднее группы 1 равно 4.600000 и рассчитывается по всем её студентам до фильтрации.
- Для баллов 5.0, 4.8, 4.8, 4.2: ROW_NUMBER = 1,2,3,4; RANK = 1,2,2,4; DENSE_RANK = 1,2,2,3.
- После всех демонстраций и проверок исходные строки сохранены, журналы аудита пусты: демонстрационные изменения откатились.

Проверки содержат 21 диагностическую ветвь THROW и воспроизводятся запуском `08_Проверки.sql` после подготовки и тематических скриптов. Тестирование проводилось на учебных данных отдельной базы; для другой базы требуется совпадение схемы, указанное в README.
