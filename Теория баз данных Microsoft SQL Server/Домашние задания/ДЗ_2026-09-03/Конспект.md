# Конспект: переход к Microsoft SQL Server

## 1. Назначение SQL Server

Microsoft SQL Server — реляционная система управления базами данных компании Microsoft. Она хранит данные в таблицах, обрабатывает запросы, поддерживает связи, ограничения, транзакции и управление доступом. На сервере можно создавать представления, процедуры, функции и триггеры.

SQL — язык работы с реляционными данными. Команды `SELECT`, `INSERT`, `UPDATE`, `DELETE` позволяют получать, добавлять, изменять и удалять строки. Эти основные идеи сохраняются при переходе с MySQL или PostgreSQL, но синтаксис отдельных команд различается.

## 2. SQL и T-SQL

T-SQL (Transact-SQL) — диалект и расширение SQL, используемое SQL Server. Помимо запросов он поддерживает переменные, условия, циклы, обработку ошибок и серверную программную логику.

```sql
DECLARE @age INT = 18;

IF @age >= 18
    PRINT N'Совершеннолетний';
ELSE
    PRINT N'Несовершеннолетний';
```

Локальная переменная начинается с `@`. Её объявляют через `DECLARE`, а присваивают значение через `SET` или `SELECT`. Несколько инструкций в одной ветке условия объединяют в `BEGIN ... END`.

## 3. Организация объектов

Иерархия: **экземпляр SQL Server → база данных → схема → объект**.

- Экземпляр — отдельная работающая среда движка SQL Server, к которой подключается клиент. На компьютере может быть несколько экземпляров.
- База данных — набор данных и объектов внутри экземпляра. Например, `CollegeDB`.
- Схема — пространство имён внутри базы. Например, `college` или стандартная схема `dbo`.
- Объект — таблица, представление, процедура или функция.

В имени `CollegeDB.college.students` указаны база, схема и таблица. Внутри выбранной базы обычно достаточно `college.students`. Схемы помогают группировать объекты и управлять правами доступа.

```sql
CREATE DATABASE CollegeDB;
GO
USE CollegeDB;
GO
CREATE SCHEMA college;
GO
```

`USE` выбирает базу для последующих команд. `GO` разделяет пакеты инструкций в SSMS и sqlcmd; это команда клиентского инструмента, а не инструкция T-SQL. Локальная переменная не сохраняется между пакетами, разделёнными `GO`.

## 4. Системные базы

- `master` — сведения об экземпляре и его базах.
- `model` — шаблон для новых баз.
- `msdb` — служебные данные, в том числе сведения о заданиях SQL Server Agent.
- `tempdb` — временные объекты и промежуточные результаты.

Учебные таблицы следует создавать в собственной пользовательской базе.

## 5. Объекты базы

Таблица хранит строки и столбцы. Первичный ключ однозначно определяет строку, внешний ключ связывает таблицы. Представление (`VIEW`) задаёт сохранённый запрос. Хранимая процедура содержит логику и запускается командой `EXEC`. Функция возвращает значение или таблицу. Триггер автоматически выполняется при определённых событиях; например, DML-триггер связан с таблицей или представлением.

## 6. Типы данных и ограничения

- `INT`, `BIGINT` — целые числа.
- `DECIMAL(p,s)` — точные числа: `p` задаёт общее число цифр, `s` — число цифр после запятой.
- `VARCHAR(n)` — строковые данные; поддержка символов зависит от сопоставления и кодировки.
- `NVARCHAR(n)` — Unicode-строки, удобные для кириллицы.
- `DATE` — дата; `DATETIME2` — дата и время.
- `BIT` — значения 0 и 1, а также `NULL`, если он разрешён.

`NOT NULL` запрещает отсутствие значения, `PRIMARY KEY` задаёт первичный ключ. Для Unicode-литерала используют префикс `N`: `N'Иван'`.

```sql
CREATE TABLE college.students
(
    id INT IDENTITY(1,1) PRIMARY KEY,
    name NVARCHAR(100) NOT NULL,
    age INT NOT NULL
);
```

`IDENTITY(1,1)` означает начало с 1 и шаг 1. При вставке обычной строки `id` не указывают. Пропуски в значениях возможны; уникальность здесь обеспечивает первичный ключ.

## 7. Отличия синтаксиса

В MySQL часто используют `AUTO_INCREMENT`, в PostgreSQL — `SERIAL` или identity-столбцы, а в SQL Server — свойство `IDENTITY`. PostgreSQL `SERIAL` опирается на отдельную последовательность и значение по умолчанию.

Вместо `LIMIT 3` для получения первых трёх строк в SQL Server можно написать:

```sql
SELECT TOP (3) id, name, age
FROM college.students
ORDER BY id;
```

Порядок нужно задавать явно. Без `ORDER BY` конкретный состав первых строк не гарантирован.

Полезные функции:

- `GETDATE()` — текущие дата и время сервера, тип `DATETIME`.
- `SYSDATETIME()` — текущие дата и время, тип `DATETIME2(7)` с большей точностью дробной части.
- `SCOPE_IDENTITY()` — последнее сгенерированное значение `IDENTITY` в текущем сеансе и области выполнения.
- `ISNULL(выражение, замена)` — замена `NULL` заданным значением.
- `COUNT(*)` — количество строк результата.

## 8. Инструмент SSMS

SQL Server Management Studio — клиентское приложение для подключения к SQL Server, выполнения запросов и управления объектами. SSMS и сервер — разные компоненты: данные обрабатывает сервер, а SSMS отправляет команды и показывает результаты.

В Object Explorer можно открыть базы, таблицы, представления и другие объекты. Список схем выбранной базы доступен запросом `SELECT * FROM sys.schemas;`.

## Вывод

При переходе на SQL Server сохраняются принципы реляционных баз данных. Нужно освоить T-SQL, различать экземпляр, базу и схему, а также учитывать особенности `IDENTITY`, `TOP`, Unicode-строк и разделителя `GO`.
