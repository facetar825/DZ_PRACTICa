## Как запустить

1. Открыть в SSMS `00_Подготовка_базы.sql` и выполнить целиком. Он создаёт учебную базу CollegeDB_HW_20261005, если её ещё нет; существующая база не пересоздаётся.
2. Открыть и выполнить `Практика.sql` целиком, включая GO. Другие домашние работы для запуска не требуются.

SQL проверен на локальном Microsoft SQL Server 2025 в составе исходного набора. Демонстрационные изменения откатываются; определения объектов сохраняются. При необходимости запуска в базе преподавателя изменить USE при наличии совместимой схемы.
