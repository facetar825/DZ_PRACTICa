# Асинхронность и Event Loop

[Конспект](<../../Конспекты/тема_03_Event_Loop/README.md>) · [Практика и результаты](<../../Лабораторные и Практические работы/ПР_03_Event_Loop/README.md>)

## Вопросы для самопроверки

1. Синхронная операция удерживает управление до окончания. Асинхронная позволяет программе продолжить работу и обработать результат позже.
2. Организует запуск обработчиков, когда события или операции готовы.
3. Таймер должен дождаться завершения текущего кода и возможности выполнить свой обработчик.
4. Колбэк связывает событие или готовый результат с нужным действием.
5. Promise представляет результат или ошибку, а `await` позволяет продолжить код после готовности Promise и обработать ошибку через `try/catch`.
6. Нет. Приостанавливается текущая async-функция, пока не будет готов результат.
7. Цикл удерживает основной поток, поэтому обработчик таймера не может запуститься вовремя.
8. ОС уведомляет Node.js о готовых сетевых операциях, и цикл событий вызывает обработчики соответствующих сокетов.
9. Сигнал о том, что производитель данных опережает потребителя. При `write() === false` следует дождаться `drain`.
10. Ожидания могут перекрываться, но обработчики JavaScript на одном основном потоке выполняются по очереди.
