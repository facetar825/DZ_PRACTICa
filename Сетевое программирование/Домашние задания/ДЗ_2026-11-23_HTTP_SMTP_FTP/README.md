# Прикладные протоколы HTTP, SMTP и FTP

[Конспект](<../../Конспекты/тема_07_Прикладные_протоколы/README.md>) · [Практика](<../../Лабораторные и Практические работы/ПР_07_HTTP/README.md>)

## Ответы на вопросы для самопроверки

1. Правила построения сообщений, разрешённые действия и смысл ответов.
2. HTTP-запрос — прикладное сообщение. TCP-соединение — транспортный канал, который может переносить несколько запросов.
3. Стартовая строка, заголовки, пустая строка и необязательное тело.
4. GET запрашивает представление ресурса. POST передаёт данные для обработки.
5. Content-Type сообщает формат тела, например text/plain или application/json.
6. 200 — успех, 201 — ресурс создан, 400 — неверный запрос, 404 — ресурс отсутствует.
7. 404 является полученным ответом HTTP-сервера, значит обмен уже состоялся.
8. Повторение одинакового запроса имеет тот же предполагаемый эффект, что и однократное выполнение.
9. SMTP обеспечивает отправку и пересылку. Для чтения предназначены IMAP и POP3.
10. FTP использует собственные управляющее и информационное соединения, SFTP работает поверх SSH. FTPS — FTP с TLS.
