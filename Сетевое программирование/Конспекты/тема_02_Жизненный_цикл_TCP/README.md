# Жизненный цикл TCP-соединения

Сервер вызывает `listen()`, клиент инициирует соединение через `net.createConnection()`. Событие `connect` означает, что установлен транспортный канал. Сервер получает отдельный `net.Socket` на каждого клиента. У соединения есть локальный и удалённый адреса и порты.

`data` приносит порцию байтов. `end` означает, что другая сторона завершила отправку, а `close` сообщает, что сокет закрыт. `error` сообщает о сбое сокета. Ошибки прослушивания обрабатываются отдельно на объекте сервера.

`socket.end()` штатно завершает исходящую сторону после очереди записи. `socket.destroy()` прекращает работу с сокетом, оставшиеся данные могут потеряться. `setTimeout(10000)` обнаруживает бездействие и вызывает событие `timeout`. Дальнейшее действие выбирает обработчик.

Типичные ошибки: `EADDRINUSE` — порт уже занят, `ECONNREFUSED` — соединение отклонено, `ECONNRESET` — соединение сброшено, `ETIMEDOUT` — операция не завершилась вовремя.

[Документация Node.js по TCP-сокетам](https://nodejs.org/api/net.html).
