# ПР 03. Event Loop

1. `node order.mjs` вывел синхронные сообщения 1 и 2, затем микрозадачу Promise (3), затем таймер (4).
2. `node blocking.mjs` показал задержку около 2004 мс при таймере на 100 мс. Пока выполнялся цикл, таймер не мог получить управление.
3. Для многоклиентского эксперимента запусти [NetLab](<../ПР_02_NetLab_TCP/README.md>) и три экземпляра клиента. Клиент А отправил `/say Привет`, клиент Б увидел сообщение и получил три подключения по `/list`, клиент В закрыл свой сеанс через `/quit`. Повторные `/list` и `PING` от Б вернули два подключения и `PONG`.

Для проверки отправляй команды с паузами меньше 10 секунд: в NetLab действует тайм-аут бездействия.
