# ПР 08 WebSocket Echo

Требуется Node.js 22 или новее и пакет ws. В этой папке выполни:

```powershell
pnpm install --frozen-lockfile
node server.mjs
```

Можно использовать `npm install` при установленном npm. Открой http://127.0.0.1:3061/ и нажми «Подключиться». Отправь PING и две произвольные строки. Каждая вернётся с префиксом ECHO. Затем нажми «Отключиться» — клиент начнёт Close handshake с кодом 1000.

В DevTools → Network → WS выбери /ws. Статус рукопожатия — 101, в Messages видны отправленные и полученные сообщения. Эту часть можно проверить вручную через локальную страницу.

Сервер принимает до 2048 байт UTF-8, отклоняет двоичные данные и проверяет Origin локальной страницы. Сообщения выводятся через textContent. Ошибки и закрытия записываются в журнал. Для повторного подключения есть отдельная кнопка.

Проверка в терминале — `node tests/smoke.mjs`. Она проверяет рукопожатие, три текстовых эха, отказ для двоичного сообщения, Close 1000, независимость двух клиентов, лимит сообщения и отказ чужому Origin.

## Сравнение способов обмена

- fetch запускает HTTP-запрос от клиента и возвращает ответ сервера. Завершение ответа не требует закрытия TCP-соединения.
- node:net позволяет обеим сторонам передавать байты, границы сообщений задаёт приложение. end заканчивает исходящую передачу.
- WebSocket после рукопожатия предоставляет двусторонний обмен сообщениями и собственную процедуру Close. Одно сообщение может состоять из нескольких фреймов.
