# ПР 07 Прикладные протоколы

Запусти `node hello-http.mjs` в этой папке. Открой http://127.0.0.1:3040/.

В другом терминале выполни `curl.exe -i http://127.0.0.1:3040/`. Ожидаются статус 200, заголовок `Content-Type: text/plain; charset=utf-8` и тело «Привет от NetLab!». В консоли сервера будут метод и путь запроса.

Для анализа в браузере открой F12 → Network, обнови страницу и выбери запрос к корню. Сопоставь URL, метод GET, статус 200, заголовки и Response с выводом curl. Дополнительный запрос favicon зависит от браузера.

Сервер демонстрационный: любой путь и метод получают ответ 200. Его назначение — показать структуру обмена. HTTP определяет запросы к ресурсам, SMTP передаёт письма через команды EHLO, MAIL FROM, RCPT TO, DATA и QUIT, а FTP использует управляющее соединение и отдельный канал данных для файлов.
