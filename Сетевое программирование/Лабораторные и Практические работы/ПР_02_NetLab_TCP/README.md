# ПР 02. NetLab и жизненный цикл TCP

Запусти `node server.mjs` и `node client.mjs` в разных терминалах из этой папки. Протокол: одна команда UTF-8 на строку. Можно ввести `PING`, `TIME`, `BYE`, `/say текст`, `/list` или `/quit`.

1. В обычном сеансе клиент получил `PONG`, время в ISO 8601 и `BYE`. Затем клиент зарегистрировал `END` и `CLOSE`.
2. После остановки сервера клиент получил `ECONNREFUSED`, события `connect` не было. Попытка запустить второй сервер на том же порту дала `EADDRINUSE`.
3. При 10 секундах бездействия сервер зарегистрировал `TIMEOUT`, отправил одноимённый ответ и вызвал `end()`. Если клиент не завершает передачу, сервер через две секунды освобождает сокет вызовом `destroy()`.
4. В PowerShell `netstat -ano | Select-String '127\.0\.0\.1:3001\s+'` показывает прослушивание 3001 и текущие соединения. После отключения клиента его соединение перестаёт быть `ESTABLISHED`, а сервер остаётся в `LISTENING`.
