# Практическая работа №7 HTTP-сервер NetLab

В этой папке выполни `node server.mjs`. Открой http://127.0.0.1:3041/. Внешние пакеты не нужны, требуется Node.js 22+.

## Маршруты

- GET / — HTML со ссылками.
- GET /api/status — service, status, eventsCount, requestsCount, time. Счётчик учитывает все запросы, включая текущий и ошибочные.
- GET /api/about — название и версия.
- GET /api/stations — три учебных компьютера.
- GET /api/events и POST /api/events — просмотр и создание события.
- GET /api/events/:id — событие или 404.
- DELETE /api/events/:id — 204 без тела или 404.
- GET /api/slow?ms=3000 — асинхронная задержка, ограниченная диапазоном 0–5000 мс.
- GET /api/error — учебный ответ 503.

## Проверка через PowerShell

```powershell
curl.exe -i http://127.0.0.1:3041/api/status
curl.exe -i http://127.0.0.1:3041/missing
$body = @{ station = 'PC-07'; message = 'REQUEST_HELP' } | ConvertTo-Json
Invoke-RestMethod -Uri 'http://127.0.0.1:3041/api/events' -Method Post -ContentType 'application/json' -Body $body
```

Корректный POST возвращает 201. Неверный JSON, пустое поле, неверная структура или длина возвращают 400. station допускает 1–40 символов после trim, message — 1–120. Лимит тела 4096 байт, превышение возвращает 413. Неподдерживаемый MIME-тип возвращает 415. Неверный метод известного маршрута возвращает 405 и Allow. Неизвестный ресурс возвращает 404.

В DevTools → Network можно сопоставить метод, статус, заголовки и тело. Просмотр DevTools выполняется вручную.

## Результаты и ответы

Терминальная проверка прошла для всех маршрутов, 200/201/204/400/404/405/413/415/503, счётчика, чтения и удаления события. Пока /api/slow ждал таймер, /api/status ответил отдельно. Общая проверка всех трёх работ запускается из ../netlab-09 командой node tests/smoke.mjs.

1. node:http разбирает HTTP-запросы и формирует ответы. node:net предоставляет TCP-поток.
2. req — входящий запрос с методом, адресом, заголовками и потоком тела. res — исходящий ответ.
3. Content-Type сообщает формат тела, например application/json.
4. 404 приходит внутри HTTP-ответа. ECONNREFUSED означает отказ транспортного подключения.
5. JSON может содержать любые типы и значения, поэтому поля проверяются перед использованием.
6. setTimeout оставляет Event Loop свободным для других запросов.
7. События хранятся в RAM и после перезапуска очищаются.
