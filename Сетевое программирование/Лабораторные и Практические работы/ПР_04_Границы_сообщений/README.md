# ПР 04. TCP и границы сообщений

Запусти `node server.mjs` и `node client.mjs` в двух терминалах. Сервер слушает `127.0.0.1:3002`. Клиент отправляет две команды одной записью и разрезает третью внутри первой буквы слова «Привет». После получения трёх ответов клиент завершает соединение.

```
ACK: PING
ACK: TIME
ACK: ECHO Привет
```

Сервер ищет байт LF, накапливает незавершённую часть и декодирует только полную строку. CRLF тоже принимается. На строку отведено не более 2048 байт до LF. Превышение лимита и на полной строке, и до появления разделителя приводит к ответу `ERROR` и закрытию соединения.

Границы `write()` не гарантируют границы события `data`. В проверке с паузой между частями сервер не отправил преждевременный ответ и восстановил строку после прихода остатка.
