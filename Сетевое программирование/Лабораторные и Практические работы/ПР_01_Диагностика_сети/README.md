# ПР 01. Диагностика сети в Windows

Запуск из PowerShell в этой папке: `./diagnose.ps1`. Для проверки порта предварительно запусти [сервер NetLab](<../ПР_02_NetLab_TCP/README.md>).

1. `ipconfig` выводит IPv4, маску и шлюз. Смотри их в блоке подключённого адаптера. Маска определяет границу подсети, шлюз служит следующим узлом для выхода из неё. Значения домашней сети смотри в локальном выводе скрипта.
2. `ping -n 2 127.0.0.1` вернул два ответа без потерь. Адрес относится к этому же ПК, пакеты не уходят в локальную сеть.
3. `nslookup nodejs.org` вернул A и AAAA записи. Пример полученного A-адреса: `104.16.213.131`. Ответ DNS может меняться.
4. При работающем NetLab `netstat -ano` показал `127.0.0.1:3001` в состоянии `LISTENING`. После подключения добавились записи `ESTABLISHED`: клиент обращается к 3001 со своего временного порта.
