## Размещение новых работ

Сначала выбирайте папку предмета, затем тип работы. Каждое задание или проект храните в отдельной папке.

Для предметов «Теория баз данных Microsoft SQL Server» и «Основы алгоритмизации и программирования» созданы разделы:

- `Конспекты/тема_номер/`
- `Домашние задания/ДЗ_дата/`
- `Лабораторные и Практические работы/ЛАБ_номер/` или `ПР_номер/`
- `Проекты/название_проекта_дата/`
- `Контрольные работы/КОНТРОЛЬ_номер/`

Пример пути для проекта по SQL Server:
`Теория баз данных Microsoft SQL Server/Проекты/Учёт_библиотеки_2026-09-22/`.

Пример пути для домашнего задания по алгоритмизации:
`Основы алгоритмизации и программирования/Домашние задания/ДЗ_2026-09-22/`.

Предмет определяйте по условию задания, а не только по языку программирования: работы по алгоритмизации не нужно автоматически относить к отдельному предмету C++.

Подробные правила именования и сдачи находятся в [Требования.md](Требования.md).
