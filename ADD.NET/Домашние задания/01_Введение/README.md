# 01. Введение в ADO.NET и архитектура доступа к данным

Источник: `Введение в ADO.NET и архитектура доступа к данным.pdf`.

## Краткий конспект

ADO.NET — набор средств доступа к данным в .NET. C# описывает поведение приложения, SQL — операции над данными, SQL Server хранит и обрабатывает данные, а провайдер Microsoft.Data.SqlClient связывает приложение с сервером.

Схема: пользователь → C#-приложение → слой доступа ADO.NET → Microsoft.Data.SqlClient → SQL Server → результат → приложение.

Порядок работы: строка подключения → SqlConnection → Open → SqlCommand → метод выполнения → обработка результата → Dispose. SqlParameter передаёт значения, SqlDataReader читает строки, SqlTransaction объединяет операции. Подключённая модель читает данные при открытом соединении; отключённая хранит копию в DataTable/DataSet. EF Core скрывает часть низкоуровневой работы за объектами, Dapper упрощает отображение результатов SQL на объекты.

## Ответы по порядку

1. ADO.NET — технология и набор классов .NET для доступа к источникам данных.

2. Для подключения, выполнения SQL, получения результатов и изменения данных.

3. ADO.NET работает на стороне приложения; SQL Server — отдельная СУБД, которая хранит данные и выполняет команды.

4. SQL — язык запросов; ADO.NET — механизм отправки этих запросов и чтения результатов из .NET.

5. Провайдер — реализация доступа к определённому источнику данных через классы ADO.NET.

6. В работах используется Microsoft.Data.SqlClient.

7. SqlConnection представляет соединение с SQL Server.

8. Open открывает логическое подключение, при необходимости используя пул соединений; при неудаче возникает исключение.

9. SqlCommand хранит текст команды, параметры, ссылку на соединение и при необходимости транзакцию.

10. ExecuteScalar возвращает первый столбец первой строки; остальные данные игнорируются. При отсутствии строки возвращается null, при SQL NULL — DBNull.Value.

11. Строка подключения задаёт сервер, базу, способ проверки подлинности и дополнительные параметры.

12. Это разные уровни: язык программирования, язык запросов, технология доступа и СУБД.

13. Подключённый доступ использует открытое соединение при чтении; отключённый позволяет обрабатывать загруженную копию после его закрытия.

14. DataTable хранит одну таблицу в памяти: столбцы, строки, ограничения и состояния строк.

15. Чтобы понимать соединения, SQL, параметры, транзакции и стоимость запросов, которые ORM частично скрывает.
