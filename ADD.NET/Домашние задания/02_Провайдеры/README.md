# 02. Провайдеры данных и конфигурация подключения в ADO.NET

Источник: `Провайдеры данных и конфигурация подключения в ADO.NET.pdf`.

## Краткий конспект

Провайдер реализует доступ к конкретной СУБД. Для SQL Server используется Microsoft.Data.SqlClient. Строка подключения вынесена в appsettings.json в раздел ConnectionStrings под именем CoffeeShop.

ConfigurationBuilder загружает JSON, затем переменные окружения: более поздний источник переопределяет предыдущий. GetConnectionString("CoffeeShop") читает ConnectionStrings:CoffeeShop. Переменная ConnectionStrings__CoffeeShop задаёт тот же ключ. SqlConnectionStringBuilder позволяет собирать строку через типизированные свойства. Пароли в репозиторий не помещают.

## Ответы по порядку

1. Набор классов ADO.NET, реализующих соединения, команды и чтение данных для конкретного источника.

2. Microsoft.Data.SqlClient.

3. Для указания адреса сервера, базы, аутентификации и параметров соединения.

4. Изменение окружения потребует правки кода; также легко случайно опубликовать секреты.

5. Для внешних настроек приложения, включая именованные строки подключения.

6. Возвращает значение ConnectionStrings:CoffeeShop либо null, если ключ отсутствует.

7. Чтобы подключить переменные окружения к конфигурации и переопределять настройки JSON.

8. Двойное подчёркивание обозначает разделитель вложенных ключей: ConnectionStrings:CoffeeShop.

9. Builder задаёт параметры через свойства, проверяет известные ключи и корректно формирует строку; готовая строка — текстовый результат.

10. История Git сохраняет опубликованные секреты; получивший пароль может обратиться к базе. Секреты хранят вне исходников.
