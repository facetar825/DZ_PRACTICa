# 05. Чтение результатов SQL-запросов с помощью SqlDataReader

Источник: `Чтение результатов SQL-запросов с помощью SqlDataReader.pdf`.

## Краткий конспект

SqlDataReader последовательно читает результат при открытом подключении. Первоначально курсор находится перед первой строкой. Read перемещает его вперёд и возвращает bool. HasRows сообщает о наличии строк, но не заменяет Read.

GetInt32, GetString, GetDecimal и GetBoolean читают соответствующие типы без произвольного преобразования. Индексы соответствуют порядку столбцов SELECT. SQL NULL проверяется через IsDBNull. Reader, command и connection освобождаются через using. В задании доступность хранится как bit, цена как decimal(10,2).

## Вопросы из лекции

1. Для чего нужен SqlDataReader?

2. Что возвращает метод Read()?

3. Почему нельзя читать строку до вызова Read()?

4. Чем reader["name"] отличается от reader.GetString(1)?

5. Почему важен порядок столбцов в SELECT?

6. Для чего используется HasRows?

7. Как проверить , содержит ли столбец NULL?

8. Почему тип метода чтения должен соответствовать типу столбца ?

9. Можно ли использовать параметры вместе с ExecuteReader()?

10. Чем ExecuteReader() отличается от ExecuteScalar()?

## Ответы по порядку

1. Для последовательного чтения строк результата SQL-запроса.

2. true, если удалось перейти к следующей строке; false, если строки закончились.

3. Курсор ещё не указывает на строку результата.

4. Индексатор ищет столбец по имени и возвращает object; GetString(1) читает строковое значение второго столбца.

5. Числовые индексы зависят от порядка столбцов в SELECT; его изменение требует корректировки индексов.

6. Для проверки, есть ли строки в результате, без перемещения курсора.

7. Вызвать reader.IsDBNull(индекс).

8. Типизированные методы не выполняют произвольных преобразований; несовместимый тип приводит к исключению.

9. Да, параметры задаются у SqlCommand перед ExecuteReader.

10. Reader позволяет читать набор строк; Scalar возвращает только первый столбец первой строки.

## Выполненная практическая часть

Программа читает минимальную цену, передаёт @price типа Decimal(10,2), выбирает доступные товары строго дороже неё, выводит id, name, price, is_available типизированными методами. Пустой результат обрабатывается отдельно.
