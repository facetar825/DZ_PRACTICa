# 04. Параметризованные SQL-запросы и SqlParameter

Источник: `Параметризованные SQL-запросы и SqlParameter.pdf`.

## Краткий конспект

Параметризованный запрос содержит заполнители @id, @price и другие; значения передаются отдельно через Parameters. Это предотвращает интерпретацию пользовательского значения как SQL-кода. Параметры представляют значения, но не имена таблиц или столбцов.

SqlParameter задаёт имя, SqlDbType, размер, значение, а для Decimal — Precision и Scale. AddWithValue определяет тип по значению, что не всегда совпадает с типом столбца. Поэтому в практике типы указаны явно. Для SQL NULL передаётся DBNull.Value. Проверка пользовательского ввода дополняет параметризацию.

## Ответы по порядку

1. SQL-команда с заполнителями, значения которых передаются отдельно от текста SQL.

2. Для описания имени, типа, размера, направления и значения параметра.

3. Конкатенация создаёт риск SQL-инъекции, проблем с кавычками, форматом чисел и дат.

4. SQL-инъекция — изменение смысла SQL-команды через ввод, который небезопасно включили в её текст.

5. В первом варианте 5 встроено в текст; во втором значение отдельно передаётся параметром @id.

6. Например command.Parameters.Add("@id", SqlDbType.Int).Value = id.

7. Да: VALUES(@full_name, @phone, @email).

8. Да: SET price = @price WHERE id = @id.

9. Да: WHERE id = @id.

10. Добавляет параметр и выводит его SQL-тип из переданного значения.

11. Для соответствия схеме БД, предсказуемых преобразований и точного задания типа/размера.

12. Через DBNull.Value, например параметр.Value = DBNull.Value.

## Выполненная практическая часть

Реализованы поиск, изменение цены, добавление и удаление клиента. Последние три операции сохраняют изменения в учебной базе.

| Запрос | Параметр | Тип SQL / C# | Пример значения |
|---|---|---|---|
| Поиск товара | @id | Int / int | 1 |
| Изменение цены | @id; @price | Int / int; Decimal(10,2) / decimal | 1; 250.00m |
| Добавление клиента | @full_name | NVarChar(200) / string | Александр Мингазов |
| Добавление клиента | @phone | NVarChar(30) / string или DBNull.Value | +79001234567 |
| Добавление клиента | @email | NVarChar(254) / string или DBNull.Value | student@example.test |
| Удаление клиента | @id | Int / int | ID добавленного клиента |

Удаление клиента с заказами отклоняется внешним ключом, ошибка выводится программой.
