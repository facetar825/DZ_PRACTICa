# 08. Отключённая модель ADO.NET- DataTable, DataSet и SqlDataAdapter

Источник: `Отключённая модель ADO.NET- DataTable, DataSet и SqlDataAdapter.pdf`.

## Краткий конспект

DataTable хранит таблицу в памяти, DataColumn описывает столбец, DataRow — строку. DataSet объединяет таблицы, DataRelation связывает их по столбцам. SqlDataAdapter.Fill загружает результаты SQL. После загрузки соединение можно закрыть, фильтровать и сортировать копию без новых SQL-запросов.

RowState: Detached — вне коллекции строк, Added — добавлена, Unchanged — без изменений, Modified — изменена, Deleted — помечена на удаление. AcceptChanges принимает состояния только в памяти и не сохраняет данные в SQL Server. RejectChanges отменяет локальные изменения. Для сохранения через Update нужны InsertCommand, UpdateCommand, DeleteCommand; необходимо учитывать конфликты одновременного редактирования.

## Вопросы из лекции

1. В чём отличие подключённой модели от отключённой ?

2. Что хранится в DataTable?

3. Для чего используются DataRow и DataColumn?

4. Что делает SqlDataAdapter.Fill()?

5. Можно ли обрабатывать DataTable после закрытия подключения ?

6. Для чего нужен DataSet?

7. Что такое DataRelation?

8. Изменится ли SQL Server после присваивания row["price"] = 250m?

9. Что означают состояния Modified и Added?

10. Чем SqlDataAdapter.Update() отличается от Fill()?

## Ответы по порядку

1. Подключённая модель читает через действующее соединение; отключённая обрабатывает локально загруженные данные.

2. Схема столбцов, строки, ограничения и информация о состояниях строк.

3. DataRow представляет строку и её значения; DataColumn — имя, тип и свойства столбца.

4. Выполняет SelectCommand и заполняет DataTable или таблицы DataSet.

5. Да, данные уже находятся в памяти.

6. Для хранения нескольких таблиц, отношений и ограничений в памяти.

7. Отношение между родительскими и дочерними столбцами таблиц DataSet; его задают явно.

8. Нет, изменится только локальная строка; нужен отдельный механизм записи.

9. Modified — ранее загруженная строка изменена; Added — новая строка добавлена в таблицу.

10. Fill загружает данные; Update отправляет локальные изменения через настроенные команды вставки, изменения и удаления.

## Выполненная практическая часть

В DataSet загружаются categories и products. После закрытия соединения DataTable.Select фильтрует доступные товары и сортирует их по цене. Создаётся DataRelation, выводятся товары по категориям. Для первой строки показаны Unchanged → Modified → Unchanged через изменение цены и RejectChanges; пустая таблица обрабатывается.
