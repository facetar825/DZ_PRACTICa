# Практическая работа №2 — Выполнение SQL через SqlCommand

Выполнил: **Мингазов Ахнаф**. Проект: **AdoNetPractice02**.

Выполнены все 10 заданий, самостоятельная статистика и дополнительное меню:

| Пункты меню | Результат |
|---|---|
| 1–5 | Количество товаров, список, клиенты, заказы, максимальная цена |
| 6 | Добавление собственного товара: название, категория и цена |
| 7 | Добавление Мокка по фиксированным значениям, изменение цены на 250, проверка цены, удаление |
| 8 | Средняя и минимальная цена |
| 9 | Количество заказов со статусом «Выдан» |
| 10 | Название текущей базы |
| 11 | Количество доступных товаров |

Сценарий Мокка получает ID через SCOPE_IDENTITY и изменяет/удаляет именно созданный товар. Другие одноимённые строки не затрагиваются. Собственный товар из пункта 6 остаётся в базе.

Проверка исходных данных: 6 товаров, 5 доступных, 3 клиента, 2 заказа, 1 выданный заказ. Пункт 7 должен показать добавлено 1, изменено 1, цена 250, удалено 1; итоговое количество товаров не меняется.

**Вывод:** ExecuteScalar получает одно значение, ExecuteReader — набор строк, ExecuteNonQuery выполняет изменение и возвращает число затронутых строк. Выбор зависит от нужного результата.
