## Выполненные задания

1. JOIN, GROUP BY, количество оценок и среднее по grades для каждого студента. LEFT JOIN сохраняет студентов без оценок.
2. CTE и общий рейтинг RANK по убыванию среднего балла.
3. Рейтинг внутри групп через PARTITION BY group_id.
4. Представление college.StudentRating, проверка всех строк и отдельно ИС-31.
5. Процедура college.GetStudentsByMinGrade с сортировкой и проверкой двух порогов.
6. Скалярная college.GetStudentStatus для статуса успеваемости.
7. Inline TVF college.GetStudentsByGroup и дополнительный фильтр по баллу.
8. Таблица college.student_changes, AFTER UPDATE триггер через inserted/deleted, проверки одного и нескольких студентов и отсутствия фактических изменений.

Итоговый запрос объединяет представление, статус, рейтинг внутри группы и количество оценок.

## Запуск и проверка

В SSMS подключитесь к учебному серверу. На этом компьютере доступен `(localdb)\CodexSqlPractice` с проверкой подлинности Windows. Нужна CollegeDB со схемой college и таблицами groups, students, grades. Для новой базы используйте [CollegeDB_dump.sql](CollegeDB_dump.sql). Он останавливается при существующей базе без удаления. Если одноимённая база имеет другую схему, используйте отдельное имя, согласованно заменив его в обоих файлах.

Основной SQL-файл выполните целиком с разделителями GO. Повторный запуск допускается: CREATE OR ALTER обновляет объекты, тестовые изменения студентов и аудита откатываются.

На исходном наборе: 3 группы, 10 студентов, 30 оценок; итоговый запрос возвращает 10 строк. Порог 4,5 соответствует 6 студентам. После тестов балл студента 1 остаётся 4,70, новых записей аудита нет. Сохранённый средний балл и среднее отдельных оценок — разные показатели и могут отличаться.
