# Практическая работа №1 — Первое подключение

Выполнил: **Мингазов Ахнаф**. Проект: **AdoNetPractice01**.

Выполнены задания 1–9 и самостоятельная часть. Создан AdoNetPractice01 с Microsoft.Data.SqlClient. Db.Open создаёт SqlConnection и вызывает Open. Через отдельные SqlCommand и ExecuteScalar получаются имя базы, имя сервера, время сервера, количество товаров, минимальная и максимальная цена. Дополнительно выводится название самого дорогого товара. При пустой таблице MIN/MAX отображаются как «Нет данных».

На исходных данных: 6 товаров, минимальная цена 120, максимальная 280, самый дорогой товар — Чизкейк. Дата и имя сервера берутся непосредственно из SQL Server.

**Вывод:** SqlConnection управляет соединением, SqlCommand отправляет запрос, ExecuteScalar возвращает первое значение результата. Команды и соединение освобождаются через using, ошибки выводятся пользователю.
