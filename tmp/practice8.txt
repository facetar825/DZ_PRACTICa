Часть  2. Загрузка  товаров  в  DataTable
Создайте  метод  LoadProducts(string connectionString), который  загружает  товары  и
возвращает  DataTable.
static DataTable LoadProducts(string connectionString)
{
    string sql = """
        SELECT id, name, category_id, price, is_available
        FROM products
        ORDER BY id
        """;
    using SqlConnection connection = new SqlConnection(connec
tionString);
    using SqlDataAdapter adapter = new SqlDataAdapter(sql, co
nnection);
    DataTable table = new DataTable("products");
    adapter.Fill(table);
    return table;
}
Вызовите  метод  и  выведите  количество  строк :
DataTable products = LoadProducts(connectionString);
Console.WriteLine($"Загружено товаров: {products.Rows.Coun
t}");
Обратите  внимание : метод  Fill() синхронный . Соединение , переданное
адаптеру  в  закрытом  состоянии , может  открываться  адаптером  на  время
загрузки  автоматически .
