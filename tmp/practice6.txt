Часть  4. Асинхронный  поиск  по  минимальной  цене
Реализуйте  метод  ShowProductsFromPriceAsync(string connectionString, decimal minPrice).
Используйте  параметризованный  запрос :
SELECT id, name, price
FROM products
WHERE price >= @min_price
ORDER BY price;
Требования :
Пользователь  вводит  минимальную  цену .
Значение  передаётся  через  параметр  @min_price.
Запрос  выполняется  через  ExecuteReaderAsync().
Строки  читаются  через  ReadAsync().
При  отсутствии  совпадений  выводится  понятное  сообщение .

Часть  6. Обработка  ошибок
Добавьте  try/catch вокруг  вызовов  методов  работы  с  базой .
Для  ошибок  SQL Server используйте  SqlException, для  некорректного  ввода
пользователя  — безопасную  проверку  int.TryParse() и  decimal.TryParse().
Не  формируйте  SQL запросы  через  конкатенацию  с  пользовательским
вводом .

Часть  8. Отмена  длительной  операции
Дополните  один асинхронный  метод  необязательным  аргументом  
CancellationToken и  передайте  его  в  OpenAsync(token) и  ExecuteReaderAsync(token) или  
ExecuteScalarAsync(token).
При  вызове  создайте  CancellationTokenSource и  установите  
CancelAfter(TimeSpan.FromSeconds(5)). Обработайте  OperationCanceledException.
Если  запрос  завершается  быстро  и  отмена  не  успевает  сработать  — это
нормально . Не  пытайтесь  искусственно  замедлять  рабочий  SQL Server.
