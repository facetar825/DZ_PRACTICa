Цель  работы
Научиться  выносить  параметры  подключения  SQL Server из  исходного  кода
C# в  файл  appsettings.json, считывать  настройки  с  помощью  ConfigurationBuilder
и  выполнять  запросы  с  использованием  отдельной  конфигурации .
База  данных :coffee_shop. Время : около  8090 минут .

Часть  3. Чтение  конфигурации
В  Program.cs загрузите  настройки :
using Microsoft.Extensions.Configuration;
IConfiguration configuration = new ConfigurationBuilder()
    .SetBasePath(AppContext.BaseDirectory)
    .AddJsonFile("appsettings.json", optional: false)
    .AddEnvironmentVariables()
    .Build();
string connectionString = configuration.GetConnectionString
("CoffeeShop")
    ?? throw new InvalidOperationException("Строка подключени
я не найдена.");

Часть  4. Проверка  подключения
Создайте  метод  CheckConnectionAsync(string connectionString), который  асинхронно
открывает  соединение  и  выводит  имя  текущей  базы :
using Microsoft.Data.SqlClient;
static async Task CheckConnectionAsync(string connectionStrin
g)
{
    await using SqlConnection connection = new SqlConnection
(connectionString);
    await connection.OpenAsync();
    using SqlCommand command =
        new SqlCommand("SELECT DB_NAME()", connection);
    string databaseName = (string)(await command.ExecuteScala
rAsync())!;
    Console.WriteLine($"Подключено к базе: {databaseName}");
}
Вызовите  метод  с  полученной  строкой  подключения . Убедитесь , что
выводится  coffee_shop.

Часть  6. Работа  с  несколькими  настройками
Добавьте  в  appsettings.json раздел  Application:
{
  "ConnectionStrings": {
    "CoffeeShop": "Server=localhost;Database=coffee_shop;Trus
ted_Connection=True;TrustServerCertificate=True;"
  },
  "Application": {
    "Title": "Управление кофейней",
    "ShowPrices": true
  }
}
Получите  и  выведите  название  приложения :
string title = configuration["Application:Title"] ?? "Приложе
ние";
Console.WriteLine(title);
При  выводе  каталога  используйте  ShowPrices: если  значение  true, показывайте
цену  товара ; иначе  выводите  только  его  название . Для  преобразования
значения  используйте  bool.TryParse().

Требования :
Строка  подключения  получается  через  
configuration.GetConnectionString("CoffeeShop").
Ни  один  метод  работы  с  SQL Server не  должен  содержать  жёстко
прописанную  строку  подключения .
SQL запросы  выполняются  асинхронно  ( как  в  предыдущей  практической
работе ).
Поиск  по  названию  использует  параметр  @search.
Результаты  списка  читаются  через  SqlDataReader.
Отсутствие  результатов  и  ошибки  подключения  обрабатываются
понятными  сообщениями .
