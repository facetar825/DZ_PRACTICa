Тема
Комплексная  работа  с  возможностями  Microsoft SQL Server: запросы , CTE,
оконные  функции , представления , хранимые  процедуры , пользовательские
функции  и  триггеры .
Цель  работы
Закрепить  основные  навыки  работы  с  Microsoft SQL Server и  проверить
умение  применять  изученные  механизмы  базы  данных  в  рамках  одной
небольшой  информационной  системы .
В  ходе  работы  необходимо :
выполнять  аналитические  запросы ;
использовать  CTE;
применять  оконные  функции ;
создавать  представления ;
создавать  и  вызывать  хранимые  процедуры ;
создавать  пользовательские  функции ;
создавать  триггеры ;
проверять  работу  разработанных  объектов .
