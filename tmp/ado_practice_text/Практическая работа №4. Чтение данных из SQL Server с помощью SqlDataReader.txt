Цель  работы

последовательно  читать  строки  результата , работать  с  типами  данных  C# и
обрабатывать  пустые  результаты  запроса . Используется  база  данных  
coffee_shop.

string sql = @"
    SELECT id, name, price, is_available
    FROM products";
using SqlConnection connection = new SqlConnection(connection
String);
connection.Open();
using SqlCommand command = new SqlCommand(sql, connection);
using SqlDataReader reader = command.ExecuteReader();
while (reader.Read())
{
    int id = reader.GetInt32(0);
    string name = reader.GetString(1);
    decimal price = reader.GetDecimal(2);
    bool isAvailable = reader.GetBoolean(3);
    Console.WriteLine($"{id}. {name}");
    Console.WriteLine($"Цена: {price} руб.");
    Console.WriteLine($"Доступен: {(isAvailable ? "Да" : "Не
т")}");
    Console.WriteLine();
}
Порядок  столбцов  в  запросе  должен  соответствовать  индексам ,
используемым  в  методах  чтения .

Часть  4. Поиск  товара  по  идентификатору
Пользователь  вводит  id, программа  выводит  название , цену  и  доступность
найденного  товара . Используйте  параметризованный  запрос :
SELECT id, name, price, is_available
FROM products
WHERE id = @id;
Передайте  идентификатор  через  параметр  @id. Если  товар  не  найден ,
сообщите  об  этом  пользователю . Поскольку  идентификатор  уникален ,
результат  содержит  не  более  одной  строки .
Часть  5. Поиск  товаров  по  названию
Добавьте  поиск  товаров  по  части  названия .
SELECT id, name, price
FROM products
WHERE name LIKE @search;
Передайте  параметр  с  символами  % в  начале  и  конце . Например , поиск  по
слову  кофе должен  выводить  товары , в  названии  которых  встречается  эта
последовательность . Выведите  идентификатор , название  и  цену  каждого
совпадения . Если  совпадений  нет , выведите  сообщение .

Часть  7. Формирование  отчёта  по  заказам
Выведите  список  заказов  из  таблицы  orders. Для  каждого  заказа  отобразите
идентификатор , дату  оформления , статус  и  идентификатор  клиента .

FROM orders;
Для  даты  используйте  GetDateTime(), для  остальных  полей  — методы ,
