# ДЗ 7. Телеметрия марсохода

Панель только для просмотра. Данные подсистем и заряд батареи заданы в `app.py`. Jinja2 выводит карточки, меняет их оформление по статусу, отмечает перегрев и обрабатывает пустой список. Индикатор заряда меняет цвет при 20% и 50%.

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Открыть http://127.0.0.1:5007/.
