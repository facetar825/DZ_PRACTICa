# ДЗ 1 Docker. Установка и аккаунт

1. В PowerShell от имени администратора выполни `wsl --install --no-distribution`. Если Windows предложит перезагрузиться, перезагрузи компьютер. Проверь установку командой `wsl --version`.
2. Установи [Docker Desktop для Windows](https://docs.docker.com/desktop/setup/install/windows-install/) с поддержкой WSL 2. Открой Docker Desktop и прочитай условия при первом запуске.
3. Создай аккаунт или войди в [Docker Hub](https://hub.docker.com/). После запуска Docker Desktop проверь работу командой `docker run --rm hello-world`.
4. Для сдачи сделай скриншот окна запущенного Docker Desktop и приложи ссылку на свой профиль Docker Hub (`https://hub.docker.com/u/ТВОЙ_ЛОГИН`).
