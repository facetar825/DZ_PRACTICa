# Домашнее задание ModelForm в Django Каталог курсов

## Запуск

В этой папке:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver 8004
```

Открыть http://127.0.0.1:8004/courses/. Сначала список пуст. «Добавить курс» открывает форму, после сохранения курс появится в каталоге. Ссылка «Редактировать» открывает существующий курс.

## Реализация

Course содержит title до 100 символов, description и seats. CourseForm — ModelForm, в Meta явно указаны модель и все три поля. clean_seats проверяет диапазон от 1 до 30 включительно. Ошибка показывается рядом с полем, введённые данные сохраняются в форме.

При редактировании в форму передаётся instance существующего Course. Корректный POST обновляет запись, затем перенаправляет в каталог. Некорректный POST оставляет базу без изменений. Формы защищены CSRF.

## Проверка

`python manage.py test` проверяет создание и редактирование, граничные значения 1 и 30, значения вне диапазона, неверный тип числа, название длиннее 100 символов, сохранение введённых значений при ошибке, отсутствие второй записи после редактирования, 404 и CSRF.

## Адреса из уточнённого задания

- /courses/ — список курсов.
- /courses/add/ — добавление курса.
- /courses/<pk>/edit/ — редактирование с instance при GET и POST.

После корректного POST выполняется переход на /courses/. Страницы / и /courses/new/ также доступны для ранее сохранённых ссылок.
