# Кинотека на Django

По указанию студента работа размещена в дисциплине «Основы алгоритмизации и программирования».

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py loaddata demo
.\.venv\Scripts\python.exe manage.py runserver 8002
```

Открыть http://127.0.0.1:8002/. Можно добавить режиссёра, жанр и фильм, фильтровать по жанру, искать по названию и сортировать по названию, году, рейтингу и длительности. Для фильма используются связи с режиссёром и жанром.

Демонстрационные записи первоначально добавлены через HTML-формы в локальную SQLite, затем экспортированы в cinema/fixtures/demo.json для воспроизводимого заполнения. Фикстуру загружать в новую учебную базу.

Режиссёр содержит имя и страну. Название жанра уникально. У фильма целочисленные год, рейтинг 0–10 и длительность 1–1440 минут. Удаление режиссёра каскадно удаляет его фильмы, удаление занятого жанра блокируется PROTECT.

## Админка

`python manage.py createsuperuser`, затем /admin/. MovieAdmin содержит list_display, list_filter и search_fields. Список фильмов использует select_related для режиссёра и жанра.

## Проверка

`python manage.py test` проверяет создание через формы, поиск, сортировку, фильтр, неверный рейтинг, уникальность жанра, CASCADE, PROTECT и CSRF. Проверки прошли. Миграции приложены.
