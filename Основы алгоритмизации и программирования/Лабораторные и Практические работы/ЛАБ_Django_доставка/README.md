# Калькулятор доставки на Django

## Запуск

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py runserver 8001
```

Открыть http://127.0.0.1:8001/. Все пользовательские поля описаны в django.forms.Form и выводятся циклом. POST защищён CSRF. При ошибках форма сохраняет введённые значения, у поля появляются сообщение и выделение.

Итог = (300 + 30 × вес) × коэффициент × (1 − скидка). Используется Decimal, округление ROUND_HALF_UP до двух знаков.

Коэффициенты standard 1, express 1.5, same_day 2. Вес ограничен 0.1–100 кг, для express не более 20 кг. Города сравниваются без учёта регистра и повторных пробелов. Телефон проверяется на формат и 10–15 цифр. Согласие обязательно.

Дополнительная функция — промокод. TOP5, TOP10 и TOP15 дают скидку 5%, 10% и 15%. Регистр не важен, неизвестный код вызывает ошибку.

## Проверка

`python manage.py test` проверяет три тарифа, все промокоды, граничные значения веса, запрет одинаковых городов, лимит express, телефон, согласие, сохранение данных при ошибке, вывод результата и CSRF. Все проверки прошли.
