# Flask авторизация с сессиями в SQLite

## Запуск

В этой папке:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Открыть http://127.0.0.1:5002/. Есть регистрация, автоматический вход после регистрации, вход по паролю, профиль и выход через POST.

## Архитектура

Весь Python-код находится в app.py, шаблоны в templates. Базы создаются автоматически в instance:

- users.db содержит только пользователей.
- sessions.db содержит таблицу серверных сессий Flask-Session.
- secret.key сохраняет ключ подписи между перезапусками. Для размещения можно задать AUTH_SECRET_KEY.

Дополнительное подключение users привязано к модели User через SQLALCHEMY_BINDS. Основное подключение используется Flask-Session для sessions.db. Поля пользователя: id, username, email, password_hash, created_at. Имя и email уникальны, нормализуются в нижний регистр. Пароль допускает 8–128 символов и хранится как хеш Werkzeug.

Каждый POST защищён Flask-WTF CSRFProtect. Сессия действует 7 дней, её идентификатор заменяется при входе. При выходе сохранённая сессия удаляется. Cookie хранит идентификатор, данные находятся в SQLite.

Срок действия сессий проверяется библиотекой. Для удаления накопленных просроченных записей доступна команда `flask --app app:create_app session_cleanup`.

## Проверка

`python tests.py` проверяет обе отдельные БД, CSRF, регистрацию, активную сессию, хеш пароля, дубликаты, неверный пароль, выход и невозможность использовать старую cookie после выхода. Проверка прошла. Вёрстка использует адаптивную ширину и перенос элементов.
